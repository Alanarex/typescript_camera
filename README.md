**Résumé (FR)** : application web progressive (PWA) en React/TypeScript avec un petit serveur Express + Socket.IO. Elle permet de prendre des photos (stockées dans le navigateur), d'afficher la position de l'utilisateur et de discuter en temps réel. L'installation et le déploiement sont décrits ci-dessous (déploiement VPS dans [docs/deployment.md](docs/deployment.md), en français).

Live demo (school-hosted, may be offline): https://alaa.khalil.angers.mds-project.fr/typescript_camera

## Features

- **Camera**: capture photos with `getUserMedia`; photos are kept in the browser's `localStorage`.
- **Gallery**: browse the captured photos.
- **Messaging**: real-time chat over Socket.IO; usernames are unique among online users.
- **Location**: geolocation with a Leaflet map.
- **Calls**: voice/phone screens that open the `tel:` handler.
- **PWA**: installable, service worker generated by `vite-plugin-pwa`.

## Architecture

- `src/`: React 18 + React Router 6 frontend (pages, components, `LocationContext`, shared Socket.IO client in `src/context/socket.tsx`). Built with Vite; the app is served under the `/typescript_camera` base path.
- `server/server.js`: Express server with Socket.IO. Messages and online users are held **in memory** (nothing is persisted). A few REST endpoints expose them (`/messages-list`, `/online-users`, `DELETE /remove-user/:username`, `DELETE /clear-messages`), optionally under `VITE_API_PREFIX`.
- Configuration comes from `.env` (see `.env.example`).

## Getting started

Requirements: Node.js 18+ and npm.

```sh
git clone https://github.com/Alanarex/typescript_camera.git
cd typescript_camera
npm install
cp .env.example .env      # then adapt the values if needed
```

Start the backend, then the frontend in a second terminal:

```sh
node server/server.js     # API + WebSocket on PORT (default 8080)
npm run dev               # Vite dev server, see the URL it prints (base path /typescript_camera)
```

`VITE_FRONTEND_URL` must match the origin Vite serves on, otherwise CORS rejects the requests.

Other scripts: `npm run build` (type-check + production build), `npm run lint`, `npm run preview`.

## What it demonstrates

- Real-time features with Socket.IO and a shared client context in React.
- Browser APIs: camera, geolocation, service worker / PWA.
- Typed React code (TypeScript) built with Vite.
- Deployment behind Apache with a WebSocket proxy and PM2 ([docs/deployment.md](docs/deployment.md)).

## Known limitations

The backend has no authentication and its state is in memory; see the security issues in the tracker before using it for anything beyond a demo.
